## 安装包中的 Skills 故障

已在现装 0.6.5 复现：`skill-manager/qml/Main.qml` 相对导入 `../../../app/qml`，便携包仅有可执行文件里的 QRC，没有相应文件目录。
打包现同时放入公共 `app/qml`、图标和所有第一方运行时模块。安装包 smoke 实际编译每个内置 Widget 的 QML，缺少导入会直接失败，Skills 必须明确输出 ready。
这条检查针对部署后的目录，不以开发目录能打开作为替代。

## 原生宿主适配和边界

- 媒体传输、思考探测、市场目录/ZIP 准备运行在独立进程；模型凭据仅经进程管道传递。供应商插件媒体使用每次请求的私有文件，避免大段 Base64 经过 GUI。
- 独立会话沿用原生 Pi 持久历史，不切换前台聊天。按插件实例和桌面配置限制工作目录、模型、工具与审批；句柄失效即拒绝，禁止桌面管理工具，不继承危险操作放行。队列、事件、历史及结果均有上限和截断说明。
- 保留原生的子代理 Skills 过滤、完整 transcript 状态和可配置 output-continuation；它们不能被 Python 桥接投影替换。
- Python 的“源码 Preview 安装”依赖 Python/PySide 运行应用，不能直接用于 C++ 可执行文件。C++ 继续采用已校验的原生二进制更新；本次不增加无法编译/运行的 Python 源码更新入口。
- Python 仓库的 Windows 滚动 Preview/发布编排属于该仓库工作流，不复制成 C++ 的发布动作。C++ 使用本仓库的四平台构建与已验证产物发布工作流。
- 操作系统登录设置在源码和隔离验收中禁用，避免改动用户真实启动项；独立纯逻辑测试使用临时路径。
