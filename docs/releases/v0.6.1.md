# Umeko-Desktop v0.6.1

## 中文

- 与 Python 0.6.1 同步 Widget 能力。插件管理移到「设置 → Agent」，聊天右下角提供最近插件按钮和紧凑列表，按钮跟随聊天区域并在窄窗中吸附。
- 新增应用级终端：终端列表和内容上下排列，支持可调比例、上下分栏、取消分栏、ANSI 着色、中文输入与复制粘贴。将终端附加到聊天后，Agent 可读取和操作同一个终端，执行过程直接可见；切换聊天或收起页面保留进程。
- 新增官方桌宠 Widget，提供八奈见动画、任务状态、点击互动、拖动、右键设置和自定义形象导入。使用原生 C++ 服务低频观察任务状态，隐藏时卸载动画解码器。
- Widget 支持会话级和应用级生命周期，以及无界面的常驻后台服务。通过统一的 `umeko_desktop` 接口发现文档、调用公开方法、查询结果和推送回执；消息始终绑定原始聊天和工作目录。
- 文件管理器支持双击附加文件和完整右键操作；版本管理提供紧凑折叠、分支选择、diff 菜单和附加到聊天。补齐内置图标目录、自定义图标及缺失图标回退。
- 工具调用中的文件可点击预览，并共用聊天文件卡片的右键菜单。Provider 插件与 Widget 插件文档和 SDK 分开检索。
- 标准版继续内置 Python、Node.js 和 npm，无需额外安装解释器；不再发布新的 minimal 版本。

## English

- Bring the Python 0.6.1 Widget experience to the native C++ client: Agent settings, recent Widget launcher, compact menus and responsive docking.
- Add application-lifetime shared terminals with ANSI colors, Unicode input, clipboard support, adjustable vertical layouts and reversible splits. Attach a terminal to a chat so the Agent can read and operate that exact visible shell. Closing the pane or switching chats preserves its process.
- Add the official animated desktop pet as a native C++ service, with task states, interactions, positioning, settings and data-only appearance imports. Low-frequency metadata sampling avoids scanning transcripts, and hidden pets unload their animation decoder.
- Support session and application Widgets, including headless services. Use the unified `umeko_desktop` tool for documentation, public methods, asynchronous results and delivery receipts. Keep notifications and terminal access scoped to their original chat and workspace.
- Improve file and version management, branch selection, context menus, built-in/custom icons and icon fallbacks. Tool file links open previews and share the attachment context menu.
- Separate Provider and Widget development guides and SDK discovery. Standard releases bundle Python, Node.js and npm; no new minimal editions are published.
