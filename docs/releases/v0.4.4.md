# Umeko Desktop C++ v0.4.4

- Fix blank Windows web previews by retaining complete Qt WebView frontend metadata, waiting for panel expansion before creating the surface, and synchronizing native visibility. Add a recoverable page-loading error.
- Keep sidebar resizing under the pointer. A narrow sidebar collapses after mouse release, preserves its previous expanded width, and briefly highlights the expand control. Project fold controls remain visible.
- Prefix fork titles with `(Fork1)`, `(Fork2)`, etc. so branch names remain visible in the sidebar.
- Remove hidden scrollbars that could compete with variable-height chat/history layout and cause repeated repositioning.
- Trust system-installed roots alongside the updater's bundled certificates. Automatically try verified direct access after a system-proxy connection fails, retain the successful download route, and display the actual route and useful certificate errors.
- Keep certificate, hostname and archive SHA-256 verification enabled. Proxy authentication failures remain explicit, and credentials are excluded from progress events and logs.

Validation includes real loopback HTTPS connections through direct and HTTPS-proxy routes, rejected untrusted/hostname-mismatched certificates, proxy failover, resumable-download checks and the native update interface. This release does not include the Python edition's new transcript paging backend.
