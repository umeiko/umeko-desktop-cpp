# Umeko Desktop C++ v0.5.1

## 中文

- `v0.5.1-minimal` 是最后一个维护的 minimal 版本；此后仅发布内置 Python 的 C++ 版本。README 下载入口统一指向完整发行包，历史 minimal 包继续保留在 Release 页面。
- 自定义供应商登录支持显示授权进度和随时取消；交互登录等待上限从 60 秒延长至 10 分钟，给浏览器确认预留时间，模型刷新和推理的超时保持原值。取消后不提交本轮待保存凭据。
- Provider SDK 更新至 0.2.2，新增可选的 `context.report_status(message)`；原有 API v1 插件继续兼容。
- 模型请求因证书信任链失败时，自动补用系统信任库并最多重连一次；成功后同一供应商沿用补充的信任链。
- 供应商齿轮 →「网络设置」新增 PEM CA 文件配置。额外证书与默认公共根证书合并使用，始终校验证书与域名，并保留用户选择的代理模式。
- 证书过期、域名不匹配、CA 文件无效或补充信任后仍失败时明确显示错误码与请求详情，不再作为普通断流反复重试。证书恢复只发生在握手阶段，不重放已经开始的模型输出；普通断流仍保留五次退避重试。
- 新增、编辑供应商共用独立浮窗，打开与关闭使用 PID 动画；表单适应较大的字体和较小的窗口。
- 输入框同时支持 Alt+Enter、Shift+Enter 换行，Enter 继续发送。
- 超过三分钟的 Agent 任务结束后，即使应用在前台也会提示；后台短任务保留原有通知行为。收起到后台的提示改为第一人称。
- API 代理启用时才显示侧栏运行状态；项目与会话右键菜单根据内容和窗口宽度布局，修复英文等较长文字截断，并重绘 Pin 图标。
- `config_umeko` 新增 `providers.certificate`，可按供应商设置或清除 CA 文件；网络与证书帮助按需加载。

CA 文件配置保存后下一次模型请求生效。也可使用 `UMEKO_MODEL_CA_FILE` 或 `NODE_EXTRA_CA_CERTS`；变更环境变量后须完全重启应用。模型请求证书与 npm、客户端更新下载证书分别管理。

## English

- `v0.5.1-minimal` is the final maintained minimal release. Future C++ releases include Python; README downloads point to the full packages, while historical minimal assets remain on their release pages.
- Show progress and allow cancellation during custom-provider sign-in. Extend the interactive-login limit from 60 seconds to ten minutes for browser confirmation, while preserving model-refresh and inference limits. Cancelled login operations do not commit pending credentials.
- Update the Provider SDK to 0.2.2 with optional `context.report_status(message)`, preserving API v1 plugin compatibility.
- Recover from certificate-chain trust failures by supplementing the default roots with the system trust store and reconnecting at most once. Successful recovery is reused for that provider.
- Add a provider-specific PEM CA file under the provider gear → Network settings. Public roots, certificate validation, hostname checks, and the selected proxy policy remain in effect.
- Show explicit TLS error codes and request details for expired certificates, hostname mismatches, invalid CA files, and persistent trust failures. Certificate recovery only retries failed handshakes; it never replays a model stream that has already started. Ordinary interrupted streams retain five bounded exponential retries.
- Add and edit providers in a shared floating dialog with PID opening and closing animations and a scrollable form at larger font sizes.
- Use Alt+Enter or Shift+Enter for a new line; Enter still sends the message.
- Notify users after Agent tasks longer than three minutes, even in the foreground. Existing short-task background notifications remain available, with updated first-person tray wording.
- Show sidebar API proxy status only while running. Fit project and conversation context menus to their labels and viewport, and improve the Pin icon.
- Use `config_umeko` operation `providers.certificate` to set or clear a provider CA file; network and certificate documentation remains available on demand.

Saved CA files apply to the next request. Restart the app after changing `UMEKO_MODEL_CA_FILE` or `NODE_EXTRA_CA_CERTS` in the environment. Model, npm, and application-update certificate settings are managed separately.
