# Umeko Desktop C++ v0.7.1

## 中文

- 逐 tag 同步 Python 0.6.6–0.7.1 的主要功能，并补齐已合入的 dsh ACP 和系统提示词管理。保留原生 C++ 会话历史、异步读取和渐进式内容准备。
- 修复便携包缺少公共 QML 导致 Skills 管理无法打开的问题。打包检查实际加载每个内置 Widget，补齐离线图标、纯白主题与简洁机器人资源。
- 新增可选的 DeepSeek Harness ACP 后端，支持运行时检查与下载、复用内部 API 代理或自有 ACP 配置、独立历史、排队、审批、停止和上下文恢复。后端菜单采用 Pi 官方图标与鲸鱼图标；dsh 菜单和设置入口标注黄色“实验版”。dsh 的能力仍有限，不等同于 Pi 的全部扩展与工具能力。
- 新增系统提示词 Widget，按 Pi、Skills、Umeko、Widgets、项目指令与扩展来源浏览，按工作区启停、编辑和恢复。保留原始 AGENTS 和 Skill 文件，仅内置页面可操作这些覆盖设置。
- 新增图片、语音、视频生成与辅助看图，提供独立模型配置、后台进度和取消；新增模型思考档位及参数格式自动探测、手动覆盖和关闭支持检查。
- 新增 Widget 市场入口、安装确认，以及供插件使用的独立持久会话与审批 SDK。第三方 Provider 仍需用户显式导入，不随应用自动安装。
- 改善窄窗口和大字体下输入栏的宽度分配，避免模型选择与发送按钮重叠。新增空闲 Pi 会话缓存、聊天危险操作临时授权和系统登录启动选项。
- 修复历史切换与滚动位置恢复竞态，以及 POSIX 终端清理时的读取锁问题；保留既有 PID 参数和动画。更新 Billion Context 的用途及单独安装说明。

## English

- Port the main Python 0.6.6–0.7.1 capabilities by tag, plus the merged dsh ACP and system-prompt features, while retaining native history, asynchronous reads and incremental content preparation.
- Fix missing public QML in portable packages that prevented Skills management from opening. Package checks load every built-in Widget; include offline artwork, the pure-white theme and robot assets.
- Add the optional DeepSeek Harness ACP backend: runtime checks/downloads, the internal API proxy or an explicit own ACP profile, independent history, queues, approvals, interruption and context resumption. Backend choices use the Pi and whale logos. Yellow Experimental badges identify dsh in both the menu and settings; it does not provide all Pi extension and tool capabilities.
- Add a source-aware system-prompt Widget with workspace-specific enable/edit/restore controls. Original AGENTS and Skill files are preserved, and only the built-in page can change these overrides.
- Add image, speech and video generation, auxiliary vision, model configuration, background progress and cancellation. Detect reasoning levels, parameter formats and off support, with manual overrides.
- Add the Widget market entry, installation confirmation and an independent persistent-session/approval SDK for plugins. Third-party providers remain explicit user imports.
- Prevent composer model/send overlap in narrow windows and at larger font sizes. Add idle Pi-session cache controls, temporary per-chat dangerous-operation grants and start-at-login settings.
- Fix history/scroll-restoration races and POSIX terminal read/cleanup locking without changing PID animation parameters. Clarify Billion Context's purpose and separate installation.

Parity audit: [Python tags and native adaptations](https://github.com/umeiko/umeko-desktop-cpp/blob/main/docs/parity/python-tags-066-071.md).
