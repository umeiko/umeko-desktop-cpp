# Umeko Desktop C++ v0.6.5

## 中文

- 同步近期 Python 版的主要能力与美术资源：新增 Skills 管理 Widget，按全局／工作区管理、导入和启用 Skill；附带九组可离线浏览的公共 Skills，并提供带中文／拼音搜索的斜杠菜单。
- 插件管理保持为可关闭的 Widget。支持标准 Pi、极简、默认和自定义会话配置；插件及工具均可单独开关，首次打开即可读取工具状态。补齐 Pi、Skills 和桌面设置图标。
- 外观页新增字体选择、小／中／大快捷档、30%–200% 字号和聊天行距。隐藏页面延迟排版；侧栏动画期间稳定聊天宽度。长会话与大型 Markdown／代码预览使用后台处理和分段加载。
- 增加上下文圆环的手动压缩入口，显示并持久保存压缩进度、结果和摘要；支持供应商上下文上限与自定义 K／M 长度。任务状态明确区分运行、完成、失败和停止，并保留耗时。
- 增加后台任务工具和按会话管理的输出、等待、停止能力；提供询问／全自动执行权限模式及高风险操作确认，主代理和子代理共享设置。模型上下文只传递最近的图片，历史记录完整保留。
- 桌面宠物支持本机提醒和待办；补齐网页／产物展示设置、文件双击操作及变更审查自动展开选项。供应商错误保留 HTTP 状态和脱敏详情，继续校验 TLS 证书。
- 变更审查提供可选的线性检查点历史：展开多文件差异、拖动上下分栏，以黄色标记历史、绿色标记当前、红色标记将被放弃的未来版本。未修改时可前后切换；旧版本产生新修改时放弃未来分支。恢复前校验实际文件、冲突和同工作目录任务锁，并保留内部安全记录，不改变聊天或 Git 状态。
- CodeArts 等第三方 Provider 继续独立分发，由用户显式导入，不随桌面包安装。

## English

- Bring recent Python capabilities and artwork to the native edition: a global/workspace Skills Widget, import and session controls, nine portable public Skill bundles, and a slash menu with Chinese/pinyin matching.
- Keep Pi management in a closeable Widget. Configure standard, minimal, default and custom per-chat presets, individual plugins and tools, and first-open tool inventories. Include the missing offline Pi, Skills and desktop settings icons.
- Add font selection, small/medium/large presets, 30–200% sizing and prose line spacing. Defer hidden-page layout, stabilize chat width during side-panel animation, and process long histories and large documents in bounded background windows.
- Add manual context compaction with durable progress/result/summary cards, provider context metadata and K/M overrides. Distinguish running, finished, failed and stopped tasks with persistent elapsed time.
- Add per-session background jobs, bounded output/waits and owned-process cleanup. User-selected Ask/Automatic permission modes and high-risk confirmations also apply to child agents. Limit submitted model images while preserving the original history.
- Add local pet reminders/to-dos, desktop preview options, file double-click actions and review auto-opening preferences. Preserve redacted provider HTTP details while retaining TLS verification.
- Add optional linear code-checkpoint history with multi-file diffs, draggable panes, yellow history, a green current pointer and red future checkpoints to be discarded. Switch backward or forward without new edits; a new edit discards the future. Restoration checks actual file hashes, conflicts and same-workspace task locks, retains an internal safety record, and leaves chat and Git state unchanged.
- Third-party providers such as CodeArts remain separately distributed and require explicit user import.
