- Add `config_umeko`, a single Agent entry point to inspect and manage the running desktop: providers and networks, model mappings, provider plugins, themes, appearance, Agent settings, projects, chats, MCP/extensions, API proxy and updates. Changes use native controllers and refresh the interface.
- Bundle separate on-demand management guides and operation documentation. `/help` returns the directory. The Agent is explicitly directed to Umeko's provider and theme mechanisms instead of Pi's overridden configuration.
- Support batch operations, bounded idle-task queues and originating-chat ownership when users switch the visible conversation. Redact existing credentials and distinguish queued/accepted work from applied changes.
- Fix Windows web preview deployment/visibility, sidebar dragging with collapse after release, persistent project fold controls and visible fork-title prefixes.
- Remove hidden scrollbars that could compete with variable-height history layout, and fix the embedded Yanami background resource reference.
- Prevent ordinary hover hints from consuming clicks on controls underneath; retain interactive question-mark help.
- Fix code pastes carrying IDE URI/image clipboard metadata, while preserving file-manager copies and screenshots.
- Split provider failure details into request and server-response tabs, including full response bodies, HTTP status/headers, individual HTTP exchanges and explicit connection-failure information.
- Reuse system-installed root certificates for updates and try verified direct access after system-proxy connection failures. Keep certificate, hostname and archive SHA-256 verification enabled.

Native tests exercise the real Agent tool round trip, live provider/theme/settings changes, deferred background-chat ownership, session export/fork/deletion, plugin loading and TLS/proxy updates. Standard and minimal editions share the same source commit. The Python edition's new transcript paging backend is not included in this native release.
